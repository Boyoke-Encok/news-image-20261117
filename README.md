One image summing up the world news of **Tuesday, 17 November 2026** — six
stories, drawn in code, each checked against the day's reporting.

## The six stories

1. **Kerch Bridge arch falls** (Ukraine) — Ukraine hits the Crimea link a
   second day; Russia strikes two Kyiv bridges in reply. (Al Jazeera)
2. **US jets hit Qeshm Island** (Gulf) — Washington strikes an IRGC missile
   site after drones target a US base in Bahrain; mines hit tankers in
   Hormuz. (AP, CNN)
3. **Jets scramble over Japan** (Asia) — Two suspected Russian planes enter
   Japanese airspace for about 3 minutes each; Tokyo protests. (Kyodo,
   Reuters)
4. **COP31 draft under fire** (Climate) — Ministers take over in Antalya as
   the first draft splits talks: fossil-fuel exit and $120bn a year for
   adaptation. (The National, Asia Today)
5. **UK sanctions settler firms** (Britain) — Eight West Bank builders and
   an aid-blocking group face asset freezes; Israel weighs a response.
   (Reuters, GOV.UK)
6. **US loses measles-free status** (Health) — PAHO ends the 26-year
   milestone after a year of spread; 5,412 cases in 2026. Mexico and
   Bolivia too. (Reuters, PAHO)

## The program

`entry.png` (1024×1024) is rendered from code — every panel is flat shapes
and type drawn with Pillow, no photos, no external images. `main.ts` copies
it to `/output/entry.png`, so both runs write the same bytes.
